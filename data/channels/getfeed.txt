1. 프롬프트 엔지니어링 #퓨샷 #페르소나
AI에게 모범 답안 예시를 사전 제공하거나 명확한 역할 및 금지 규칙을 부여하여 원하는 결과물을 유도하는 직관적 기법이다.

-실제 사용법: 시스템 프롬프트에 너는 데이터를 추출하는 백엔드 서버다, 인사말과 부가 설명은 절대 금지한다라고 통제 조건을 명시한다. 혹은 질문과 완벽한 정답 형태의 짝을 1에서 2개 미리 입력해두는 퓨샷 기법을 적용하여 AI가 그 패턴을 그대로 모방하도록 유도한다.

2. API 파라미터 제어 #온도조절 #JSON모드
코드 레벨에서 AI의 창의성을 통제하여 기계적이고 일관된 답변을 유도하거나, 출력 형태를 특정 데이터 구조로 물리적으로 고정하는 기술이다.

-실제 사용법: 파이썬 등에서 API를 호출할 때 temperature를 0.0으로 설정해 환각과 창의성을 억제하고 일관된 팩트 위주의 결과를 얻어낸다. 또한 출력 포맷 파라미터를 JSON 모드로 강제 설정하여, 애플리케이션이 즉시 파싱할 수 있는 규격화된 데이터만 반환하도록 코드를 작성한다.

3. 검증 및 후처리 파이프라인 #정규표현식 #자동재요청

-실제 사용법: AI 응답 앞뒤에 불필요한 텍스트가 섞였을 때 정규표현식을 이용해 중괄호 사이의 텍스트만 파싱하여 데이터베이스에 저장한다. 만약 코드가 유효한 JSON을 읽어내는 데 실패하면, 백엔드 서버가 즉시 JSON 형식이 잘못되었으니 다시 작성하라는 에러 메시지와 함께 AI API를 자동 재호출하도록 에러 복구 루프 로직을 구축한다.

4. 모델 파인튜닝 #미세조정 #데이터학습
