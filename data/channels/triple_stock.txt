[2026-08-25 01:02] [NVIDIA Groq 3 LPX 양산 시작… Agentic AI용 초고속 추론 가속기]

*발표 개요
-NVIDIA가 8월 24일 Groq 3 LPX의 양산을 시작했다고 발표
-Groq 3 LPX는 Interactive AI Inference Accelerator
-NVIDIA Vera Rubin 플랫폼을 확장하는 형태로 제공
-Agentic AI의 초고속 토큰 생성을 목적으로 설계
-Nebius가 Groq 3 LPX를 채택하는 첫 번째 AI Cloud 사업자

*Groq 3 LPX의 역할
-Agentic AI는 하나의 작업을 완료하기 위해 수백~수천 단계의 추론을 수행할 수 있음
-각 단계에서 대규모 토큰을 생성하기 때문에 토큰 생성속도가 Agent의 작업속도에 영향을 미침
-Groq 3 LPX는 Vera Rubin NVL72의 추론 성능을 확장해 토큰 생성속도를 높이는 역할
-특히 개별 사용자를 위한 토큰 생성속도인 Interactivity를 높이도록 설계
-NVIDIA는 Context가 큰 작업과 지연시간에 민감한 Agentic AI 작업을 주요 활용처로 제시

*Artificial Analysis 벤치마크
-Groq 3 LPX는 Artificial Analysis 테스트에서 초당 3,400개의 Output Token을 기록
-테스트 모델은 오픈소스 Agentic 모델 Gemma 4 31B
-Context Length는 100,000 Token
-NVIDIA에 따르면 해당 모델 기준 지금까지 기록된 가장 빠른 성능
-Agentic Coding 및 Latency-sensitive workload를 주요 적용 사례로 제시

*경쟁 플랫폼 대비 성능
-NVIDIA는 Groq 3 LPX가 Agent와 Latency-sensitive workload에서 가장 가까운 대안 플랫폼 대비 4배 빠른 Responsiveness를 제공한다고 설명
-Agentic Coding 작업의 경우 몇 시간이 걸리던 작업을 몇 분 단위로 수행할 수 있다고 설명
-구체적인 비교 대상 플랫폼 이름은 보도자료에서 공개하지 않음

*Agentic AI에서 필요한 두 가지 연산
-NVIDIA는 Agentic AI가 크게 두 가지 컴퓨팅 과제를 발생시킨다고 설명
-첫째는 대규모 Context를 효율적으로 처리하는 것
-둘째는 매우 낮은 Latency로 Token을 생성하는 것
-Groq 3 LPX는 이 가운데 빠른 Token Generation에 특화
-Token 생성속도가 빨라지면 Agent가 파일 확인, 코드 작성, 테스트, Tool Call, 결과 검증, 재작업을 더 빠르게 수행할 수 있음

*Vera Rubin NVL72와의 관계
-Vera Rubin NVL72는 Training과 Inference를 모두 처리하는 AI Factory 플랫폼
-Groq 3 LPX는 Vera Rubin NVL72를 대체하는 제품이 아니라 추론 성능을 확장하는 제품
-Vera Rubin NVL72가 다양한 AI 연산을 처리하고 Groq 3 LPX가 초고속 Token Generation을 담당하는 구성
-고객의 AI Factory에서 워크로드 특성에 따라 두 플랫폼을 함께 활용할 수 있도록 설계

*Nebius
-Nebius가 Groq 3 LPX를 도입하는 첫 번째 AI Cloud 사업자
-Nebius는 자사 Production Inference Platform인 Nebius Token Factory에 Groq 3 LPX를 적용할 계획
-개발자들은 기존 Nebius API를 그대로 이용하면서 Groq 3 LPX의 Token Generation 성능을 사용할 수 있음
-Nebius는 별도의 새로운 Software Stack으로 Migration할 필요가 없다고 설명

*Groq
-Nebius에 이어 AI Inference Cloud 사업자 Groq도 Groq 3 LPX의 초기 도입 사업자 가운데 하나가 될 계획
-NVIDIA 보도자료에서는 Groq와 관련된 구체적인 도입 규모나 시점을 공개하지 않음

*Vera Rubin AI Factory 구성
-NVIDIA는 Vera Rubin을 7개의 칩과 5개의 목적별 Rack을 공동 설계한 AI Factory 플랫폼이라고 설명
-Vera Rubin NVL72와 Groq 3 LPX를 고객별 AI Factory 요구에 맞춰 활용
-Frontier Model 개발사와 Open Model Service Provider 등을 주요 고객으로 제시

*함께 사용되는 NVIDIA 인프라
-NVIDIA BlueField-4 DPU
-NVIDIA Vera CPU Rack
-NVIDIA Vera BlueField-4 STX Storage
-NVIDIA Spectrum-6 SPX Ethernet
-NVIDIA는 이들 시스템을 함께 사용해 Multi-Agent System의 Throughput per Watt와 Inference Latency를 개선하도록 설계했다고 설명

*Jensen Huang 발언
